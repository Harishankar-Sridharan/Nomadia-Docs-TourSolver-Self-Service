# Where can I find my API key and the API documentation?

Find the TourSolver API documentation and the API key that you need to connect your applications to TourSolver.

## Before you begin

* Sign in to **TourSolver** with a user profile that has access to the **Configuration** page.

## Feature overview

* **TourSolver API documentation**: Describes the REST APIs of TourSolver Cloud, to create, start, and read optimizations, publish route plans to the mobile app, and follow the fulfillment.
* **API keys**: Authenticate your applications when they call the TourSolver API.

## Open the API documentation

1. Open the [TourSolver API documentation](https://toursolver.readme.io/reference/introduction).
2. Read the **Introduction**, and then select the service that you need, for example **Optimization**, **Fulfillment**, **Client**, or **User**.

## Find your API key

1. Go to **Configuration**.
2. Under **Roles & Profiles**, click **API keys**.
3. Find the key in the list, and then click the **Copy** icon.

For more information, see [Where is the API key?](https://toursolver.readme.io/reference/authentication-2) in the API documentation.

## Tips

{% hint style="info" %}
**One key per use case**: Create one API key for each integration, so that you can disable or replace one key without stopping the others.
{% endhint %}

{% hint style="warning" %}
**Keep your API key secret**: Do not share your API key by email or in a support ticket. A new key is shown only once, so copy it right away.
{% endhint %}
