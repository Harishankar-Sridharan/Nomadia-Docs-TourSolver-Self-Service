# What is the maximum number of visits that can be imported or optimized?

Find out how many visits you can import and optimize.

## Before you begin

* Know whether you use the trial version or an active subscription.

## Feature overview

| Account type | Maximum number of visits |
| ------------ | ------------------------ |
| **TourSolver Self-service trial version** | Up to **250 visits** to import and optimize. |
| **Active subscription** | From **2,000 to 4,000 visits**, depending on the constraints set for your simulation. |

## What affects the limit

Some constraints, such as multiple opening days or visit frequency, can significantly increase the computation time. They can reduce the maximum number of visits allowed.

## Tips

{% hint style="info" %}
**Keep constraints simple**: If your optimization takes a long time, check the constraints that you set for the simulation. Fewer constraints leave room for more visits.
{% endhint %}
