# What is the maximum number of visits that can be imported or optimized?

Find out how many visits you can import, optimize, and sectorize on each page of TourSolver, and what to do with a larger file.

## Before you begin

* Know whether you use the trial version or an active subscription. See [How Many Resources Can I Create?](how-many-resources-can-i-create.md).

## Feature overview

* **Customers page**: Up to **100,000** customers in one import.
* **My deliveries page**: Up to **5,000** visits to import and optimize, depending on the frequencies and the working days.
* **Sectorization**: Up to **50,000** customers.
* **Trial version**: Up to **250** deliveries, **5** deliverers, and **5** optimizations per day.

## What affects the limit

Some constraints, such as several opening days or visit frequencies, increase the computation time. They can reduce the number of visits that you can optimize at the same time.

## Import a larger file

1. Split your file into several files, for example one file per agency, per area, or per week.
2. Import and optimize each file separately.

## Tips

{% hint style="info" %}
**Keep constraints simple**: If your optimization takes a long time, check the constraints that you set for the simulation. Fewer constraints leave room for more visits.
{% endhint %}
