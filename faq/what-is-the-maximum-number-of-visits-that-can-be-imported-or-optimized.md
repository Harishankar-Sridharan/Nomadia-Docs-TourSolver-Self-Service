# What is the maximum number of visits that can be imported or optimized?

Find out how many visits you can import and optimize.

## Feature overview

* In the **TourSolver Self-service trial version**, you can import and optimize up to **250 visits**.
* With an **active subscription**, the limit ranges from **2,000 to 4,000 visits**, depending on the constraints set for your simulation.

{% hint style="info" %}
**Constraints affect the limit**: Some constraints, such as multiple opening days or visit frequency, can significantly increase the computation time and can reduce the maximum number of visits allowed.
{% endhint %}
