# Which Browsers and Systems Are Compatible with TourSolver?

Check which browsers and mobile operating systems you can use with TourSolver.

## Before you begin

* Check the browser version that you use on your computer.
* Check the operating system version of the mobile devices that your delivery people use.

## Feature overview

TourSolver is compatible with these browsers: **Google Chrome**, **Mozilla Firefox**, **Microsoft Edge**, and **Apple Safari**. The mobile app is available on **Android** and **iOS**.

### Tested and validated versions

| Platform | Versions |
| -------- | -------- |
| Google Chrome | Version 142 and above |
| Mozilla Firefox | Version 145 and above |
| Microsoft Edge | Version 142 and above |
| Apple Safari | Version 26 and above |
| Android (mobile app) | Between 8.0 and 15 |
| iOS (mobile app) | 15.5 and above |

### Browsers that are not compatible

These versions are not tested and are not compatible with TourSolver:

* Microsoft Internet Explorer 9, Microsoft Internet Explorer 10, Microsoft Internet Explorer 11

## Tips

{% hint style="info" %}
**Use a validated version**: Use one of the tested versions to get the best performance and full access to the TourSolver features.
{% endhint %}
