# How to Prioritize the Fewest Possible km / the Most Planned Customers?

Set the optimization priorities so that the algorithm favors fewer kilometers or more planned customers.

## Before you begin

* Sign in to **TourSolver**.
* Open the **Optimization Settings** during an optimization.

## Feature overview

During the optimization, you set priorities in the **Optimization Settings**, under the **Optimization Priorities** tab. These settings influence how the optimization algorithm balances your constraints.

| Parameter | Values |
| --------- | ------ |
| **Reduce kilometers** | Low / Normal / Important |
| **Reduce working time window** | Low / Normal / Important |
| **Maximize number of visits** | Low / Normal / Important |
| **Use as few resources as possible** | Low / Normal / Important |

Adjust these parameters based on your goals.

## Tips

{% hint style="info" %}
**Use different levels**: Assign a different priority level to each parameter for the best results. Setting all the constraints to **Important** usually does not produce optimal outcomes.
{% endhint %}
