# 4. Which Browsers and Systems Are Compatible with TourSolver

TourSolver is compatible with the following:

* **Google Chrome**
* **Mozilla Firefox**
* **Microsoft Edge**
* **Apple Safari**&#x20;

Below is a list of browser versions that have been tested/validated with TourSolver:

* Google Chrome: version 142 and above
* Mozilla Firefox: version 145 and above
* Microsoft Edge: version 142 and above
* Apple Safari: version 26 and above

The browser versions below are not tested or compatible with TourSolver:

* Microsoft Internet Explorer 9, Microsoft Internet Explorer 10, Microsoft Internet Explorer 11

#### TourSolver mobile app

* **Android**
* **iOS**

Here is the detailed list of versions of the mobile operating systems tested/validated with TourSolver:

* Android 5.1, 6.0, 7.0
* iOS 11.0.2, 11.4.1
