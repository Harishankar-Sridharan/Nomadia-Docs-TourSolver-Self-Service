# 3. How long are my Route optimizations kept?

The duration of the optimization can be set from the **Activity** page.

Thus, in the **Optimization** tab, TourSolver proposes to define a maximum duration for the optimization of tours. It can be set between 1 and 30 minutes.

**Tip**: the computation time of some vehicle profiles are faster than others during the [**preparation phase of the optimization**](https://www.toursolver.com/en/faq/route-optimization-computation#prep). These profiles use so-called "accelerated" graphs. So if your vehicles have the profiles "light delivery vehicle" and "truck", the preparation time will be much faster. We invite you to use this trick, in case of large volume of visits to be optimized and when you have a significant preparation time.
