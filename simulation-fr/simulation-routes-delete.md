# Supprimer des tournées

Cette page explique comment retirer les tournées sélectionnées de la simulation.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Tournées**.
2. Cochez les cases des tournées que vous souhaitez supprimer.
3. Cliquez sur la flèche déroulante **Tournées**, puis sur **Supprimer**. Vous pouvez aussi appuyer sur **Ctrl+Delete**.

## Résultat

Les tournées sont retirées de la liste du panneau **Tournées**.

## Conseils

{% hint style="info" %}
**Conserver vos modifications** : cliquez sur **Enregistrer les modifications** dans la barre d’outils pour conserver les modifications apportées à la simulation. Cliquez sur **Annuler l’action** pour annuler la dernière modification.
{% endhint %}
