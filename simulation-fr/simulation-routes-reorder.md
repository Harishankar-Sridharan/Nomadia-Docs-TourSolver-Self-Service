# Réordonner des tournées

Cette page explique comment modifier l’ordre des arrêts des tournées sélectionnées.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Tournées**.
2. Cochez les cases des tournées que vous souhaitez réordonner.
3. Cliquez sur la flèche déroulante **Tournées**, puis sur **Réordonner**. Vous pouvez aussi appuyer sur **Alt+r**.

## Résultat

Vous pouvez vérifier le nouvel ordre dans la vue de la tournée. Voir [Afficher une tournée](simulation-routes-view-route.md).

## Conseils

{% hint style="info" %}
**Déplacer un arrêt à la main** : ouvrez la tournée, puis faites glisser un arrêt par sa poignée dans le tableau des événements.
{% endhint %}
