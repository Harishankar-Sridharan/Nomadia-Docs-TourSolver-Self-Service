# Graphiques d’analyse

Cette page explique ce que montre chaque graphique du panneau **Analyse**.

## Avant de commencer

* Ajoutez le panneau **Analyse** à la page. Voir [Analyser les résultats](simulation-analysis.md).

## Étapes

1. Cliquez sur la flèche déroulante **Analyse**.
2. Cliquez sur l’un des graphiques suivants :
   * **Comparaison de la disponibilité des livreurs avec le cumul des durées de livraison (planifié/non planifié)** : compare la disponibilité des livreurs avec le total des durées de livraison, pour les livraisons planifiées et non planifiées.
   * **Nombre de livraisons par durée** : indique le nombre de livraisons pour chaque durée.
   * **Cumul par durée de livraison** : indique le cumul pour chaque durée de livraison.
   * **Nombre de fréquences de livraison** : indique le nombre de livraisons pour chaque fréquence.
   * **Nombre de livraisons par créneau horaire** : indique le nombre de livraisons pour chaque créneau horaire.
   * **Nombre de livraisons par ville** : indique le nombre de livraisons dans chaque ville.
   * **Nombre de livraisons par secteur** : indique le nombre de livraisons dans chaque secteur.
   * **Taux d’utilisation par livreurs** : indique dans quelle mesure chaque livreur est utilisé.
   * **Nombre de livraisons par département** : indique le nombre de livraisons dans chaque département.

## Résultat

Le panneau affiche le graphique que vous avez sélectionné.
