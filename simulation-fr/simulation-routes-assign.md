# Affecter des tournées

Cette page explique comment affecter les tournées sélectionnées.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Tournées**.
2. Cochez les cases des tournées que vous souhaitez affecter.
3. Cliquez sur la flèche déroulante **Tournées**, puis sur **Affecter**. Vous pouvez aussi appuyer sur **Alt+a**.

## Résultat

Les tournées sélectionnées sont affectées. Vous pouvez vérifier le résultat dans le panneau **Tournées**.
