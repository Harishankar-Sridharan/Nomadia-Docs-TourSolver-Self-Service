# Supprimer des livraisons

Cette page explique comment retirer les livraisons sélectionnées de la simulation.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Livraisons**.
2. Cochez les cases des livraisons que vous souhaitez supprimer.
3. Cliquez sur la flèche déroulante **Livraisons**, puis sur **Supprimer**. Vous pouvez aussi appuyer sur **Ctrl+Delete**.

## Résultat

Les livraisons sont retirées de la liste du panneau **Livraisons**.

## Conseils

{% hint style="info" %}
**Conserver vos modifications** : cliquez sur **Enregistrer les modifications** dans la barre d’outils pour conserver les modifications apportées à la simulation. Cliquez sur **Annuler l’action** pour annuler la dernière modification.
{% endhint %}
