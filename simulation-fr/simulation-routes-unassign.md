# Désaffecter des tournées

Cette page explique comment supprimer l’affectation des tournées sélectionnées.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Tournées**.
2. Cochez les cases des tournées que vous souhaitez désaffecter.
3. Cliquez sur la flèche déroulante **Tournées**, puis sur **Désaffecter**. Vous pouvez aussi appuyer sur **Alt+n**.

## Résultat

Les livraisons des tournées sélectionnées sont désaffectées. Vous pouvez les vérifier dans les colonnes **Planifié** et **Affecté à** du panneau **Livraisons**.
