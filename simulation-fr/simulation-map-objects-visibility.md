# Choisir ce qu’affiche la carte

Cette page explique comment utiliser **Visibilité des objets** pour choisir les objets, le style de carte et les calques du panneau **Carte**.

## Avant de commencer

* Ouvrez une simulation. Voir [Simulation](simulation.md).

## Étapes

1. Accédez à **Simulation** > **Carte**.
2. Cliquez sur **Visibilité des objets**.
3. Dans le tableau de gauche, utilisez la colonne **Voir** pour afficher ou masquer un type d’objet, et la colonne **Sélection** pour choisir ce que vous pouvez sélectionner avec l’outil **Sélection**. Les types sont **Tous**, **Tournées**, **Livraisons planifiées**, **Non affectés**, **Départs et arrivées** et **Livreurs**.
4. Sur la droite, sélectionnez un style de carte : **Carte**, **Noir & blanc**, **Satellite**, **Terrain** ou **Transport public**.
5. Utilisez les interrupteurs pour activer ou désactiver un calque : **ZFE\_ZTL**, **COMPLETE**, **ADMINISTRATIVE MAP**, **Trafic**, **Poids lourds** ou **Clusters de livraisons**.

![Le menu Visibilité des objets avec les types d’objets, les styles de carte et les calques](../.gitbook/assets/TS_Simulation_MapObjectsVisibility_001.jpg)

## Résultat

La carte affiche les objets, le style et les calques que vous avez choisis.
